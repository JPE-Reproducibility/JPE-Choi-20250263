                                    Replication Package

              “Superstars or Supervillains? Large Firms in the South Korean Growth Miracle”

                                        September 2026


            This note explains the replication package for the paper “Superstars or Supervillains? Large Firms
         in the South Korean Growth Miracle.” Table1summarizes which codes generate the outputs of the
         draft.


                                    1. Replication Steps

         To replicate the package, the procedure is as follows:
           1.Runthedo-fflesinStataPart1,locatedintheSTATAfolder.AftersettingthedirectoryinSHELL.do,
              run the following codes in order:
              (a)RunSTATA/DATA_CLEANING.do. This code cleans the dataset used for computing ffrm- and
                 sector-level datasets.
              (b)RunSTATA/CONCENTRATION.do. This code computes the concentration ffgures.
               (c)RunSTATA/TO_MATLAB.do. This code creates inputs for quantitative exercises.
              (d)RunSTATA/ESTIMATION_PROD_FUNC.do. This code creates data inputs for the production-
                 function estimation procedure.
           2.RuntheMatlabffleMATLAB_PROD_FUNC/SHELL.m,whichrunsMATLAB_PROD_FUNC/DKL_MARKUP.m,
              MATLAB_PROD_FUNC/PROD_FUNC_MARKUP.m,andMATLAB_PROD_FUNC/PROD_FUNC_BW_MARKUP.mcon-
              secutively.
              (a)MATLAB_PROD_FUNC/DKL_MARKUP.mestimates DKL markups.
              (b)MATLAB_PROD_FUNC/PROD_FUNC_MARKUP.mestimates production functions based on𝜎=5.
               (c)MATLAB_PROD_FUNC/PROD_FUNC_BW_MARKUP.mestimates production functions based on the
                 elasticity of substitution from Broda and Weinstein (2006, QJE).
           3.RunMATLAB/MATLAB_part1.m.
           4.Run Stata Part 2. Run the following codes consecutively. Stata Part 2 requires the backed-out
              ffrm-level shocks generated byMATLAB/MATLAB_part1.m.
              (a)RunSTATA/PF_EST_RESULT.do. This code reports the production-function estimation re-
                 sults.
              (b)RunSTATA/Merger.do. This code runs robustness checks regarding mergers.
               (c)RunSTATA/SHOCK_CORR.do.Thiscoderunsrobustnesschecksregardingshockcorrelations.
              (d)RunSTATA/DISTRIBUTED_LAG.do. This code estimates the distributed-lag model between
                 ffrm-level shocks and observables.
               (e)RunSTATA/spillover_region.do. This code constructs a shock series that incorporates
                 potential spatial spillovers, estimated from Choi and Shim (REStat, forthcoming).

                                              1               (f)RunSTATA/HCI_Drive.do. This code runs the HCI Drive industrial-policy event study.
              (g)RunSTATA/BRIBERY.do. This code runs external validation regarding bribery.
              (h)RunSTATA/SHOCK_VALIDATION.do. This code runs additional robustness checks that vali-
                 date the shocks.
               (i)RunSTATA/FIGURE6_scatter_plot_villain.do. This code plots Figure 6.
           5.RunMATLAB/MATLAB_part2.m.
